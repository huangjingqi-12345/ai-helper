# 患教三类报告 Markdown 结构（互斥）

Agent 写 `write_text_deliverable` 时必须按任务选用对应结构；核心数字引用脚本 `canonical_summary` / manifest。

## 数据概览 `overview_report.md`

1. **分析范围**（起止日、全平台口径）
2. **核心 KPI**（四指标 + 全周期累计说明）
3. **运营健康度**（送达/转化/完读，不重复图表逐条罗列）
4. **结构分布**（项目/渠道/内容类型，2–3 条）
5. **TOP 内容**（2–3 条，带占比）
6. **数据口径与限制**（1 段）

不写：长段环比叙事、日级趋势曲线、下月行动清单。

## 趋势分析 `trend_report.md`

1. **趋势总述**（1 段：方向 + 最强驱动）
2. **分析窗口 KPI**（四指标，标注全周期累计）
3. **日/周走势解读**（结合折线图，含异常波动日期）
4. **最近月环比**（四项核心 + 1 段原因）
5. **漏斗变化**（推送→送达→阅读）
6. **TOP 内容贡献变化**（增长/集中风险）
7. **运营建议**（2–4 条，可执行）

不写：八段式月报目录、审批生产章节。

## 月度报告 `monthly_report.md`

1. **执行摘要**（3–5 条 bullet，含 1 条下月优先级）
2. **本月 KPI**（四指标 + MoM）
3. **月内节奏**（按周峰谷，1 段）
4. **内容与项目表现**（TOP + 短板各 1–2 条）
5. **生产与审批**（发布/审批，有则写）
6. **风险与机会**（数据支撑）
7. **下月行动建议**（与 Canvas `recommended_actions` 一致）
8. **口径与限制**

不写：全年累计 KPI 作主标题、长段日级曲线复述。
