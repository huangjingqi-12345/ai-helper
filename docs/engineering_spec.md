## 1. 系统概述

### 1.1 什么是 Px-Lite？

Px-Lite 是一个面向药企的**患者教育内容运营平台**。管理患教内容的全生命周期：

```
药企提交诉求 → 运营受理 → 医生分配 → 内容创作 →
医学编辑审核 → [医学编辑修改] → PX运营审核 → 药企审核 → 患者端发布 → 行为追踪
```

### 1.5 系统层级关系（PM 已确认）

```
租户（Tenant）          ← 药企入驻的初始能力，是一切的起点
  └── 项目（Project）    ← PX 运营新建，必须关联租户
        └── 诉求（RequestTicket） ← 药企新建，必须关联已有项目
              └── 分发            ← 按诉求维度进行分发，支持多次分发
```

> **关键约束：**
> - 租户是药企入驻时的初始能力
> - PX 运营新建项目**必须关联租户**
> - 药企新建诉求**必须关联已有项目**
> - 策略分发按**诉求维度**进行
> - 支持一次分发少量，然后多次分发完成

### 1.2 三端系统

| 系统 | 用途 | 负责方 |
|------|------|--------|
| **PX**（本系统） | 内容运营、审批、分发、数据分析 | Px 团队 |
| **DX**（医生端） | 医生接收任务、创作内容、医学编辑审核 | DX 团队 |
| **CX**（患者端） | 患者浏览内容、互动行为追踪 | CX 团队 |

### 1.3 PX 系统的两个视图

| 视图 | 使用者 | 菜单项 |
|------|--------|--------|
| **运营视图** | Px 内部运营人员 | 总览、患教内容工坊、患者行为洞察、分发策略、审批中心、平台管理 |
| **药企视图** | 药企方人员 | 总览、患教内容工坊、患者行为洞察、审批中心 |

### 1.4 技术栈

- **前端:** React + TypeScript + Vite + Tailwind CSS
- **后端:** Node.js + Express + TypeScript
- **数据库:** SQLite（演示） → PostgreSQL（生产）
- **状态管理:** Zustand stores

**KPI 卡片（6 张）：**

| KPI | 计算方式 |
|-----|---------|
| 项目数 | 当前租户范围内 `count(Project)` |
| 已发布内容 | `count(ContentItem where status='published')` / `count(ContentItem)` |

| 阅读人数 | `Σ ContentItem.reads`（注：演示站显示 32,998 ≈ floor(42,314 × 0.78)） |
| 阅读次数 | `Σ ContentItem.readTimes` |
| 互动数 | `Σ (ContentItem.likes + ContentItem.favorites)` |

**项目概览区：**
- 按病种分组（当前仅"乳腺癌"）
- 显示：已发布数、推送人数、阅读人数、阅读次数、互动数
- 链接："进入项目" → `/distribute/:projectId`，"行为洞察" → `/audience`

| 方面 | 运营 | 药企 |
|------|------|------|

| KPI | 计算方式 |
|-----|---------|

**路由:** `/audience`

#### 4.3.1 布局

```
┌─────────────────────────────────────────────────────────┐

│ ┌── KPI 卡片（4 张） ──────────────────────────────────┐  │

│ └──────────────────────────────────────────────────────┘ │
│                                                          │
│ 内容 TopN                        [按阅读次数] [按互动数]    │
│ 1. 他莫昔芬 5年内分泌辅助...  推送6,225 阅读4,211 次5,399 719│
```

**KPI 卡片（4 张）：**

| 卡片 | 计算方式 |

**TopN 内容榜单：**

## 6. 关键公式与计算

| 公式 | 表达式 | 使用场景 |
|------|--------|---------|
| 阅读人数 | `floor(reads × 0.78)` | 总览、行为洞察、内容详情 |
| 互动数 | `likes + favorites` | 全平台所有 KPI（统一口径） |
| TopN 排序（按互动） | `likes + favorites + shares` | 行为洞察 TopN |
| 策略分发候选 | `titles 命中 AND pendingCount = 0`，按 `interactionScore DESC` 排序 | DoctorPolicyEditor |
| 混合分发 | 指定名额优先扣减 → 剩余按 `interactionScore DESC` 平均分配 | allocateMixed() |
| 审批 SLA 剩余 | `node.timeoutHours - (now - enteredAt) / 3600` | 审批中心 |
| 财务回款率 | `collected / (collected + outstanding)` | 财务 KPI |
